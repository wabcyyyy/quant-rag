# ADR-0003 · 飞书直连「条件转正」

- 状态：已关闭（2026-09-23 条件验证：发起人已离职，应用权限不可得 → **demo 留档，旧决策维持**）
- 关联：[ADR-0001](ADR-0001-升级范围拍板-还债优先.md) · PLAN §2「不做的事」

## 背景

PLAN §2 拍板「不对接平台 API」，理由是采集不是瓶颈、不引审批依赖。2026-09 已存在
`scripts/feishu_export_demo.py`（未接正式 ingest）：路径 A = Docx Blocks API → Block 树 →
本项目 `IntermediateDoc`（IR 契约已对齐）；路径 B = Drive Export Task → PDF/docx 落
`data/raw` → 走现有解析。demo 产物 `data/feishu/demo_ir.json` / `demo_raw_blocks.json`。

## 决策

**条件转正**：

- **权限可得** → 转正为可选第三条接入路径。约束：IR 契约不变（下游分块 / 入库 / 检索零改动，
  因此不动任何基线）；保留手动迁移为默认，API 直连为显式开关；与增量同步
  （目录 diff + sha256）+ 自动 prune 组成「数据新鲜度」闭环——幽灵块治理从「每次手动对账」
  变成「更新即对账」。PLAN §2「不做的事」条目同步修订，本 ADR 为依据。
- **权限不可得** → demo 留档作学习材料，旧决策维持，本 ADR 记录「受权限约束未转正」。

## 后果

- 转正后面试口径从「接入与平台解耦（纯防御）」升级为「解耦为主、平台直连为可选路径，
  且直连的增量同步把数据新鲜度做成闭环」；
- 需要处理 API 侧工程问题：应用级限流（demo 已按 ~5 QPS 限速）、token 刷新、
  分页游标——均为接入层内部事务，不碰 IR 之下任何一层；
- 合规面不变：语料仍不出域，权限范围最小化（只读）。
