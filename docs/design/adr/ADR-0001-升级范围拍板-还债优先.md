# ADR-0001 · 本次升级的范围拍板：还债优先

- 状态：已接受（2026-09-23 追问闭环定稿）
- 关联：[ADR-0002](ADR-0002-聚合题两段式合成.md) · [ADR-0003](ADR-0003-飞书直连条件转正.md)

## 背景

项目以「vibe-coding 起步、比较简单」自评发起本次升级。对照 2025–2026 业界生产级 RAG 共识
（hybrid+RRF 默认、rerank 高 ROI、评估与可览性为核心），自评的「简单」已过时：
**评估闭环是显著长板**（噪声地板 / 配对检验 / Holm 校正 / 跨供应商 judge / 正对照 / 伪影护栏）。
真正的缺口是文档里已记录的五处债务：

1. 聚合题检回来但没喂进 LLM（E2 证明 +26.7pt 可买，但 SLO 破 → 未交付）；
2. 已测弱项未收尾：可答题里 Hit@5 未中的共 **5 条**——term q019/q020、time_filter q063/q064
   （两题型同为 0.8333）、decision q017（0.9）；doc_date 仅覆盖 18.8%，
   而语料大量「2025年第44周」式周次可纯代码换算——**q063/q064 的逐条数据已把两者连起来**：
   年份过滤生效、无回退、gold 全军覆没（doc_coverage=0.0），指向 gold 文档无 doc_date 字段被
   过滤整族排除；
3. 基线里的未知数：真实库幽灵点数从未清点、−3.1pt 未归因、re-ingest 后缓存可吐旧答案；
4. 生产化空白：无压测、embedder 抖动（retrieve max 68s）无治理、单实例限流；
5. 业界新共识（contextual retrieval）零实验记录。

备选主线：生产化优先 / 技术纵深优先 / 面试叙事优先。

## 决策

**还债优先**：L0（地雷拆除）→ L1（弱项收尾，含 term 修复）→ L2（聚合题两段式）为主线。
**排期不设日历约束**（2026-09-23 拍板：不限期，顺序按依赖排），但范围维持克制：

- **L3 全砍**（压测 / embedder 抖动治理 / 缓存失效 / 多实例限流），维持「已知不足」口径；
- **L4 全砍**（contextual retrieval 消融留显式不做 + 重开条件，见下）；
- **term 修复保留在主线**：诊断出可修模式就修 + 重测（n=12 下 1 条 = 8.3pt，
  重测判读必须带这个功效声明）；
- **−3.1pt 归因对照顺延**：它是「未解释」不是「错误」，¥0.25 随时可补，不占主线。

红线（沿用仓库纪律）：一次只动一个检索侧变量；每项改动先声明作废哪些基线、重跑哪些数字；
新结论过配对判读 + 对应噪声地板；简历 3 条 bullet 已定稿，**本升级只为追问防守，不为简历加数字**。

## 环境事实（2026-09-23 核实）

发起人已离职：飞书 API 不可用（见 ADR-0003），但——全量语料 1130 份在本地 `data/raw`、
黄金集 v2 与 E2/P2 全部对照臂结果文件在本地 `data/eval`、API key 在 `.env`、
Qdrant 为本地 docker。**真库验收完全可行**，不依赖任何公司环境。

## 后果

- 每件事都有已量出的依据，无 speculative 开发；
- 「上线 / QPS / 多实例」类追问继续以诚实边界应对（单实例决策、已知 embedder 抖动）；
- contextual retrieval 的追问答案维持「未在自己语料上量过」——以「重开条件」的 ADR 口径应对，
  不虚构。

- **2026-09-23（执行后收口）**：升级已跑完——L2 两段式负结果收档（见 ADR-0002）、
  −3.1pt 结案（噪声）、幽灵块清点为零、周次回填落地（doc_date 覆盖率 18.8%→62.5%、
  q063/q064 翻绿）、term 拍板不修（上表）；过程发现「检索重跑地板 ≠ 0」口径修订见
  [PLAN §5.6](../PLAN.md)。
- **2026-09-23（代码与数据自审后）**：① 纠错——原文「term 是唯一 Hit@5 <0.9 的题型」不实，
  逐条数据为 term q019/q020 + time_filter q063/q064 + decision q017 共 5 条未中（README 里
  「唯一一个连碰到都没碰到」那句与它自己的分题型表矛盾，列为待修文档 bug）；② 执行顺序
  修订——**L2 两段式验收必须先于任何库变更**（prune --yes / 周次回填），否则与 A6/C25/S12
  历史臂不可比，要么违反「新旧不混用」要么多花 ¥2–3 重跑对照臂；仅报告的 prune 幂等
  可提前。执行细节见 [UPGRADE_2026.md](../UPGRADE_2026.md)。
