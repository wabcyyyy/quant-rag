# ADR-0002 · 聚合题走两段式合成（逐篇微摘要 + 聚合合成）

- 状态：**已执行并收口（2026-09-23）：验收双门槛皆未过 → 负结果收档，不转正默认口径，
  `synthesis.two_stage.enabled` 维持 false，机制与数据留档。** 验收读数与判读见
  [PLAN §5.6 Phase 1.3](../PLAN.md)；下面「验收」一节的门槛为跑前定死的原始版本，未因结果回调。
- 关联：[ADR-0001](ADR-0001-升级范围拍板-还债优先.md) · PLAN §5.5（E2 / P2 的全部数字）

## 背景

聚合题（cross_doc / time_filter，gold 中位 37 篇）是本项目最大未完成项，三条已量事实框住了设计空间：

1. **E2（2026-09-20）**：single-shot 直喂 25 块 `keypoint_recall` 0.1951 → 0.4623
   （配对差 +26.7pt，95%CI [+10.9, +42.7]，噪声地板的 8.6 倍），代价输入 3.4 倍
   （6,803 tok/条）、聚合端到端 p95 8.6s / 12.6s——**破「聚合 ≤5s」SLO，未进默认口径**。
2. **agent policy 层（P2，2026-09-21）**：与 A6 不可区分（−2.75pt，落在 3.1pt 地板内）
   且 2.2 倍成本；13/20 条一次判定就停——**no-go，`agent.enabled` 保持 false**。
3. **只动上下文预算是半个杠杆**：清单 top-8 会把 25 块预算截在 8 块（B 臂已证）。

备选：直喂 25 块转正（吃 SLO 与成本，故事是「花了钱」不是「做了优化」）/ 不动（诚实边界）/
两段式。

## 决策

聚合题（由改写预测的 cross_doc / time_filter 路由，**单发口径逐字不动**）改走两段式：

```text
top-25 检索（预算机制已存在：retrieval.aggregate_top_n）
→ 逐篇微摘要（并行、关思考、走响应缓存、每篇约 200 tok 输出、逐篇落盘供重放）
→ 聚合合成只吃摘要（token 可控），引用仍回溯原文档（[n] → doc/page/block 链路不变）
```

理由：

- 唯一有机会**同时拿到质量与 SLO** 的路线：map 段并行且可缓存，reduce 段输入可控；
- 不违反 F1 合成规则 3——逐篇枚举，不做任何跨篇合并陈述（P4 那条「放宽」线继续封着）；
- 判据与对照臂现成：`keypoint_recall`（3.1pt 重跑地板已实测）、A6 / S12 / C25 三条臂已在库，
  新增的只有两段式这一条臂；
- 与 agent no-go 构成「同一条动机下的两次尝试」完整叙事：直喂（有效但 SLO 破）→
  policy 层（无效）→ 分层合成（本次）。

## 验收

**门槛于 2026-09-23（跑之前）定死，同 agent 先例：**

| 结果 | 处置 |
|---|---|
| keypoint_recall 配对差（vs A6）**≥ +10pt**（≈3.2× 地板）**且** 聚合端到端 p95 **≤ 8s**（含 map+reduce，`--fresh-answers` 口径） | **进默认口径**：改 `configs/default.yaml`，README 聚合题基线重发 |
| 质量过、延迟不过 | 默认关 + 机制与数据留档（同 `agent.enabled` 先例） |
| 质量不过（<+10pt 或 CI 跨 0） | 记负结果，不转正；「分层摘要损失在本语料不可接受」也是合格结论 |

已定的口径边界：

- 判读在 **n=17**（20 条聚合题里拿得到 keypoint 的）上做，报结论必须带这个 n；
- 配对判读走 `compare-retrieval --metric keypoint_recall`，与 A6 基线配对；
- 微摘要必须随条目落盘（沿用 `rewritten` / trace 的重放纪律：缺记录值拒绝重放）；
- 五条入口 parity：两段式是 Orchestrator 内的分支，不是新入口——parity 矩阵加
  `mode` 之外的 `synthesis_route` 维度。

## 风险

- **微摘要信息损失**：keypoint 可能已在原文但被摘要压掉 → keypoint_recall 低于 C25 直喂。
  负结果也记录（「分层摘要的损失在本语料上不可接受」仍是合格结论），照 agent 先例处理
  （默认关、留机制与数据）。
- **map 段失败的退化路径**：逐篇摘要失败 ≤ 阈值 → 该篇用原文首块降级；超阈值 → 整题退回
  单发口径并计数（沿用 rewrite degraded 的机器标志先例：`/metrics` + `meta` 自证 + 全退化中止）。
- **缓存键**：微摘要走现有响应缓存（键含模型 + messages + 参数），重跑零成本；但答案缓存
  会掩盖真延迟——验收跑 `--fresh-answers`。
