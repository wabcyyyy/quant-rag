# ADR-0004：contextual retrieval 机制与本轮检索侧结论

- 状态：**已转正默认（2026-09-25 U3① 拍板，用户按本 ADR 读数委托执行）；检索侧读数已采；答案侧判读待 Phase C 电池**
- 日期：2026-09-25（修改轮）
- 取代：ADR-0001 中「contextual retrieval 显式不做」的重开条件——本轮就是那个
  「债务线收尾后、基线待建立的免费窗口」（SPEC A3.4：基线作废成本此刻为零）。

## 1. 决策

入库时为每个 chunk 生成一段**上下文前缀**（这个片段讨论什么事项、处于文档什么位置，
≤60 字，LLM 生成、走响应缓存），拼在被索引文本最前再嵌入/分词。机制落在
`src/doc_rag/ingest/contextual.py` + `indexer.index_parsed(ctx_mode=...)`。

消融三臂（本轮只读检索侧，`--retrieval-only`，零 LLM 答案成本）：

| 臂 | `--ctx` | dense 输入 | BM25 输入 |
|----|---------|-----------|-----------|
| ① 无前缀（现基线） | off | section_path + 正文 | 同 dense |
| ② 有前缀 | both | **前缀** + section_path + 正文 | 前缀 + section_path + 正文 |
| ③ 有前缀但不嵌入 | bm25 | section_path + 正文（与①逐字同） | 前缀 + section_path + 正文 |

③ 的存在理由：区分「前缀的**信息**价值」（BM25 词面命中）与「前缀对 dense 表示的
**扰动**收益」（嵌入空间的定位信号）。

## 2. 成本纪律（本轮实测）

- 试算先行（`--limit 2` → 5 篇直测）：每 chunk 一次调用，实测输入 ~220 / 输出 ~30
  tokens、`reasoning_effort=none`（照 judge/rewrite 先例，思考归零）。
- 全量外推：346 次新调用 ≈ 输入 7.6 万 / 输出 1 万 tokens ≈ **¥0.2**（上限 ¥10，
  实付远低于上限）。臂 ②/③ 共用同一批前缀（响应缓存命中，第二次生成 ¥0）。
- 前缀生成失败**不阻塞入库**：降级「无前缀」并计数（`ctx_prefix_failed`，
  照 `metadata.extract_metadata` 先例）；前缀文本随 payload 落盘（`ctx_prefix`）可追溯。

## 3. 检索侧结论（320 篇合成语料 · gold_core 74 条 · n=66 可判 · 每臂两遍）

| 读数 | ① 无前缀 | ③ 前缀只进 BM25 | ② 前缀双路 |
|------|---------|----------------|-----------|
| Hit@5 | 0.9091 / 0.8939（两遍） | **0.9242**（两遍） | **0.9394**（两遍） |
| Hit@8 | 0.9545 | 0.9697 | **0.9848** |
| Recall@5 | 0.9099 | 0.9250 | **0.9402** |
| Recall@清单（上限 0.9942） | 0.9476 | 0.9627 | **0.9779** |
| 归一化召回 | 0.9527 | 0.9678 | **0.9830** |
| MRR / nDCG@8 | 0.7732 / 0.8203 | 0.7884 / 0.8354 | 0.7960 / 0.8450 |

判读（retrieval-side，正式配对检验留下一轮与答案侧一次跑齐进同一 Holm 家族）：

1. **②>① 方向一致、幅度约 +3pt（≈2 条），且超过本语料实测的同配置重跑抖动**
   （同库两遍 Hit@5 极差 1.5pt ≈ 1 条）。整条清单召回 0.9476→0.9779 同样 +2 条。
2. **③>① 也为正（+1.5pt ≈ 1 条）**：前缀作为 BM25 词面信号本身就有信息价值。
3. **②>③ ≈ +1.5pt**：前缀进 dense 表示带来 BM25 之外的额外增益——两个成分
   （信息价值、表示扰动收益）方向相同。
4. 机制成本 ~¥0.2 / 索引，且有「失败降级」兜底。

## 4. 转正拍板（2026-09-25，U3①）与待下一轮的部分

- **U3① 已拍板：转正默认**。依据：②臂全指标最优（Hit@5 +3pt、Recall@清单 +3pt，
  超同库重跑抖动）、成本 ~¥0.2/索引、失败降级兜底。时序上恰在冻结与 Phase C 之前

  与 C5 消融全集一次跑齐进同一 Holm 家族；若答案侧出现倒退，回滚本决定按 L2 计价
  （≈¥30），这是拍板时已接受的风险。
